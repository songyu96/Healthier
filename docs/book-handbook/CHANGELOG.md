# 变更记录

[返回手册目录](README.md)

## 2026-09-18

- 将三类脂肪酸比例草稿中的伪对象列表改为`EVIDENCE_ONLY/TEXT`原文组件，保留完整比例原文和人工复核待办，不提升发布状态。
- 对照第一册`index_split_018.html`，将正文与术语表的密度定义统一为书中的“单位体积”口径。

## 2026-09-08

- 统一可发布知识判定，数值速查、正式/草稿学习卡和审计覆盖共用同一规则。
- 人工复核状态改为纯流程元数据，不再放宽额外测量、对象对应或原子性检查。
- 将9条含语义待办的知识降入草稿；7条无法机械证明的关系改为只保留原文直接支持的`EVIDENCE_ONLY`组件。
- 新增面向读者的人工复核清单，集中展示待确认结论、严格绑定跨度、完整原文和定位信息。
- 删除断言级自由证据上下文字段，将68条断言全部迁移到`CONTIGUOUS`或`ORDERED_LIST`两种证据模型。
- 连续证据使用相对于原始证据文本的UTF-16半开区间，并核对原始`slice(start, end)`与保存文本完全一致。
- 共享口径列表改为组级结构，逐项绑定对象跨度和测量跨度，强制顺序、边界、完整覆盖与唯一归属。
- 人工语义复核只用于标记程序无法证明的指代或推导关系，不能为跨对象错配、扩大跨度或同步篡改授权。
- 核验结果增加连续断言、共享列表、列表断言和人工复核待办/完成数量。
- 增加同步交换所有证据结构、列表遗漏/重复、单条断言滥用列表、旧字段残留及offset/text不一致等隔离测试。

## 2026-09-07

- 为每条断言增加`targetFragments`，把对象、数值、单位、比较方向和时间口径绑定到结论中的同一原子片段。
- 将多对象数值结论改为逐对象显式重复单位或时间口径，防止活动系数、食物范围等映射被交换。
- 将`targetComparators`改为带理由的结构化转换声明，目前仅允许经过双重核对的`EQ → APPROX`。
- 增加结论与片段同步篡改、活动系数互换、食物范围互换、连接词借用单位及比较符自我授权等隔离测试。
- 将数量断言的比较符、数字和单位绑定到同一局部表达，阻止多数字之间交换比较方向或借用单位。
- 为原文与摘要的精度差异增加显式`targetComparators`，并使`EQ`拒绝数值附近的方向性比较符。
- 修复三元比例共享后缀可能清空首个对象的问题，缩写后的对象识别词必须非空且唯一。
- 增加添加糖比较符互换、奶类约数改上限、三类脂肪酸首项替换及多数字单位借用等隔离测试。

## 2026-09-04

- 强化断言与结论字段的绑定，比例同时校验对象顺序与数值顺序。
- 公式正文改为必须匹配完整表达式，速查值仍允许保留右侧简写。
- 已核验数值和公式必须分别由断言覆盖正文与速查值，禁止仅靠`EVIDENCE_ONLY`通过。
- 增加只反转比例对象、只篡改公式左侧、全证据专用断言和单侧覆盖缺失的隔离回归测试。
