# 心脏疾病

[返回手册目录](../README.md)

以下内容用于理解书中的知识结构，不是可以直接执行的个人治疗方案。


## 先区分问题部位

- 心肌、心脏瓣膜、心脏传导系统和冠状动脉的问题不同。
- 心衰、动脉粥样硬化、冠心病和心律失常不能使用完全相同的饮食方案。
- 制定方案前应结合症状、心功能、血压、血脂、血糖、体重、药物和检查结果。

## 心衰

- 书中强调低钠、高营养，并关注总液体摄入。
- 液体不仅包括饮水，还包括汤、粥、奶、酸奶和其他饮品。
- 钠和液体目标必须结合心功能、浮肿、尿量、药物和医生要求，不能自行套用固定数值。
- 控制钠和水的同时，要避免能量和蛋白质不足。

## 动脉粥样硬化和冠心病

- 应同时关注吸烟、血压、血糖、体重、活动、脂肪酸结构和整体饮食。
- 作者强调减少反式脂肪酸，并增加蔬果等提供的抗氧化营养来源。
- 不能把冠心病饮食简单概括为“低脂、低盐、低糖”，而忽略营养不足和个体差异。
- 书中疾病章节中的高脂肪或蛋白质比例属于作者方案，不能直接用于自我治疗。

## 心律问题

- 心律异常可能涉及心脏结构、传导、药物、电解质和生活方式等多种原因。
- 书中关注钙、镁、钾等矿物质和整体营养，但不能根据心悸自行补充电解质。
- 出现持续心悸、胸痛、晕厥或呼吸困难时，应优先接受医学检查。
