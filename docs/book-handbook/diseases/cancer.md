# 肿瘤营养

[返回手册目录](../README.md)

以下内容用于理解书中的知识结构，不是可以直接执行的个人治疗方案。


## 评估重点

- 关注体重变化、进食量、胃肠症状、治疗方式、炎症、肌肉量和化验结果。
- 营养不良可能影响治疗耐受和恢复，但营养支持不能替代肿瘤治疗。
- 对代餐、补充剂和所谓抗癌食品，要检查实际成分、剂量和潜在相互作用。

## 营养支持方向

- 首先减少继续造成营养损失的因素，并保证能够达到的能量和蛋白质目标。
- 蛋白质需要随营养状态、代谢压力、肝肾功能和治疗阶段变化。
- 恶心、呕吐、早饱、黏膜炎、腹泻、口干、味觉改变和厌食，需要采用不同的进食策略。
- 必要时改变食物质地、餐次、温度和调味，提高实际摄入量。
- 持续监测症状、体重、饮食、化验和生活质量，再调整方案。

## 需要避免的误解

- 不能通过挨饿把癌细胞单独“饿死”。
- 吃得有营养不等于一定会促进肿瘤生长。
- 全素饮食、只喝汤、忌所谓“发物”或依赖单一补充剂，不能替代完整营养支持。
- 书中病例的肿瘤指标变化和治疗结果不能证明饮食可以单独治愈肿瘤。
