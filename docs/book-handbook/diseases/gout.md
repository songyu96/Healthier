# 痛风和高尿酸

[返回手册目录](../README.md)

以下内容用于理解书中的知识结构，不是可以直接执行的个人治疗方案。


## 基础认识

- 嘌呤代谢会产生尿酸，尿酸水平同时受生成和排泄影响。
- 高尿酸是检查结果，痛风还涉及结晶、炎症和疾病阶段。
- 不吃肉或海鲜并不能自动排除其他原因。

## 书中的六项原则

- 限制膳食嘌呤摄入。
- 控制总能量。
- 平衡搭配三大产能营养素。
- 保证适当饮水。
- 戒酒。
- 注意食物烹调方法。

## 其他重点

- 肉汤、鱼汤和火锅汤可能溶入较多嘌呤，不能只看是否吃了肉。
- 含糖饮料和甜食也可能影响尿酸代谢。
- 饥一顿、饱一顿以及快速减重可能造成代谢波动。
- 干菌类和泡发后的同重量食物，嘌呤浓度不能直接比较。
- 海鲜、豆类和蔬菜不能只按名称一刀切，应结合品种、处理方式、数量和疾病阶段。
- 书中关于豆类和海鲜的具体限制属于作者方案，应结合现行医疗建议复核。
