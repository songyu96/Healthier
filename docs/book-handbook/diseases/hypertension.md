# 高血压

[返回手册目录](../README.md)

以下内容用于理解书中的知识结构，不是可以直接执行的个人治疗方案。


## 书中的问题框架

- 盐摄入较多可能增加钠负荷和血容量。
- 优质蛋白质摄入不足可能影响整体营养状态和组织维护。
- 活动不足会影响体重和外周循环负担。
- 情绪和压力会造成血压波动。

## 饮食关注点

- 保持整体饮食均衡。
- 根据体重和活动量控制总能量。
- 适量控制盐，而不是机械追求完全无盐。
- 保证适量蛋白质和合理脂肪来源。
- 增加富含钾、钙、镁和膳食纤维的食物。
- 结合运动、睡眠和情绪管理。
- 书中介绍DASH饮食，但强调要结合中国人的食物和饮食习惯调整。

## 需要避免的误解

- 单独吃某一种食物不能代替综合降压管理。
- 饮酒不能作为降压方法。
- 鸡蛋、动物性食物或所有脂肪不应因为高血压被一概禁止。
- 降压药是否调整必须由医生结合血压和病情决定。
