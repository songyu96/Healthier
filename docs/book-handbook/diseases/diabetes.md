# 糖尿病和血糖异常

[返回手册目录](../README.md)

以下内容用于理解书中的知识结构，不是可以直接执行的个人治疗方案。


## 血糖来源与去向

- 血糖来源包括食物、肝糖原分解和糖异生。
- 血糖用于组织供能、形成糖原储备，也可能在过量时转化为其他储存形式。
- 胰岛素参与血糖进入细胞和多种代谢过程。
- 空腹血糖、餐后血糖和糖化血红蛋白反映的时间范围不同。

## 饮食管理工具

- 升糖指数反映含等量碳水的食物引起血糖升高的相对速度。
- 血糖负荷同时考虑升糖指数和实际碳水摄入量。
- 混合进食蛋白质、脂肪和膳食纤维，可能改变食物消化和血糖上升速度。
- 食物颗粒大小、加工和烹调程度也会影响消化速度。
- 食物交换份可以在控制总量的前提下增加选择空间。
- 少量多餐是否适用，要结合药物、血糖规律和全天能量判断。

## 个体化原则

- 糖尿病前期、已确诊糖尿病和出现并发症时，关注点不同。
- 肥胖者和消瘦者不能使用同一套能量目标。
- 需要同时考虑降糖药或胰岛素，避免饮食变化引起低血糖。
- 水果不是绝对禁忌，但要考虑品种、数量、时间和全天碳水总量。
- “无糖食品”不代表不含淀粉、其他糖类或能量。
