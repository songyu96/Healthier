# 慢性肾病

[返回手册目录](../README.md)

以下内容用于理解书中的知识结构，不是可以直接执行的个人治疗方案。


## 基础认识

- 肾脏参与排泄代谢产物，并调节水、电解质、酸碱和多种内环境指标。
- 慢性肾病需要结合分期、尿蛋白、肌酐、血磷、血钾、营养状态和是否透析判断。
- 只看一张化验单或只限制一种营养素，可能忽视营养不良风险。

## 蛋白质原则

- 书中指出慢性肾病1～2期通常不必像后期那样严格限制蛋白质。
- 3～4期案例口径约为每日每千克体重0.8克蛋白质。
- 透析后蛋白质需要可能增加，书中使用每日每千克体重约1.2克的口径。
- 这些数字属于疾病分期方案，必须由专业人员结合个人情况确定。

## 其他关注点

- 在限制蛋白质时仍要保证足够能量，避免身体分解自身组织。
- 血磷控制要同时考虑食物营养价值，不能只按磷含量粗暴删除全部高营养食物。
- 钠、钾、水和液体限制取决于病情、尿量和治疗方式。
- 肾移植或透析不是营养管理的终点，仍需要持续监测。
