# 血脂异常

[返回手册目录](../README.md)

以下内容用于理解书中的知识结构，不是可以直接执行的个人治疗方案。


## 基础概念

- 食物脂肪、体脂和血脂是不同概念。
- 血脂包括甘油三酯、胆固醇和磷脂等成分，并通过脂蛋白运输。
- “高密度”和“低密度”描述的是运输颗粒，不是胆固醇分子本身有好坏之分。
- 食物中的脂肪不会简单、原样地等同于血液中的脂肪。

## 饮食关注点

- 甘油三酯增高时，要同时检查碳水化合物、添加糖、酒精和总能量。
- 脂肪管理包括总量、脂肪酸结构、反式脂肪酸和食物中的胆固醇。
- 书中强调适量天然脂肪、增加鱼类等ω-3来源，并减少反式脂肪酸。
- 蔬菜、水果和其他食物提供的抗氧化营养素也是作者关注的方向。
- 不能靠全素饮食或某一种所谓“降脂食物”解决所有血脂问题。
- 使用他汀等药物时，应由医生评估疗效、不良反应和相关营养问题。
