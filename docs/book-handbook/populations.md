# 不同人群的营养重点

[返回手册目录](README.md)

## 1. 婴幼儿和儿童

- 生长发育期同时需要能量和结构原料，不能套用成年人的低脂、低能量饮食。
- 书中指出0～6个月婴儿膳食中的脂肪供能比例很高，约为47%；随着年龄增长逐渐接近成年人水平。
- 添加辅食应逐步扩展食物种类，并注意蛋白质、脂类、维生素和矿物质来源。
- 儿童时期形成的食物接受习惯会影响以后饮食，应把握食物学习和尝试的阶段。

## 2. 青少年

- 青春期同时发生身体和大脑快速发育，能量和多种结构营养素需求增加。
- 不恰当节食、长期不吃动物性食物或饮食种类过少，可能造成营养来源不足。
- 体重和外形不能作为评价营养状态的唯一标准。

## 3. 孕产妇和哺乳期女性

- 孕产期和哺乳期的营养需求不同于普通成年人。
- 备孕期需要关注叶酸、铁、锌、钙等营养来源。
- 产后“清淡”不能理解为只吃少油少蛋白的单一食物。
- 孕产期疾病、体重变化和补充剂使用应接受专业指导。

## 4. 老年人

- 老年人可能出现咀嚼、吞咽、消化能力下降和食量减少。
- 总能量需求可能下降，但蛋白质和微量营养素不能随之过度减少。
- 应关注肌肉减少、体重变化、骨骼健康和独居造成的饮食单一。
- 必要时可以少量多餐，并通过改变食物质地提高可接受性。

## 5. 不同工作和活动人群

- 体力劳动者需要较高能量，并保证谷物、蛋白质和其他营养素充足。
- 脑力劳动者活动量可能较低，但不能因此取消主食、脂肪或动物性食物。
- 经常运动和大量出汗者要同时考虑能量、水和电解质损失。
- 工作名称不能直接决定活动等级，应观察实际站立、步行、负重和运动时间。

## 6. 患病人群

- 患者饮食的重点是根据现阶段最主要的问题进行纠偏。
- 同一种疾病可能同时存在肥胖、消瘦、营养不良、用药和器官功能异常等不同情况。
- 普通人的饮食目标不能直接转化成患者方案。
- 饮食调整后需要复查和重新评价，而不是长期固定不变。
