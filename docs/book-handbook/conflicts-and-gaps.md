# 书内冲突、歧义与知识缺口

## 常见认识误区

- 体重正常不代表营养结构和身体组成一定正常。
- 吃得少、吃得素不必然等于健康。
- 清淡饮食不等于没有肉、蛋、奶、鱼和油脂。
- 血脂高不等于所有脂肪都必须停止摄入。
- 体脂、血脂和食物脂肪不是同一概念。
- 胆固醇是人体需要的结构和功能物质，不能简单理解为越低越好。
- 粗粮、蔬菜和膳食纤维不是越多越好。
- 豆制品不能完全代替肉、蛋、奶和鱼。
- 果汁不能代替完整水果，水果也不能代替完整正餐。
- 白粥容易消化，但不代表营养全面或适合所有胃病患者。
- 单一所谓“降压、降脂、降糖、抗癌”食物不能代替整体饮食和医疗管理。
- 国外膳食指南需要结合本国饮食结构理解，旧版指南也不能冒充当前最新版。
- 非特异症状不能用来直接判断缺少哪一种营养素。
- 营养补充剂不是越多越好，食物来源与大剂量补充剂的风险不同。

## 书内冲突、歧义与知识缺口

- 书中的35%动物性、65%植物性食物没有明确计量口径。
- 健康人蛋白质存在供能比例和每千克体重两种算法，不能假装完全一致。
- 脂肪章节同时存在20%～30%范围和“不低于30%”的表述。
- 脂肪酸结构存在“饱和、单不饱和、多不饱和各占三分之一”和`3∶4∶3`两种表述，应保留章节语境，不能合并成一个精确值。
- `ω-3∶ω-6＝1∶4～6`是书中给出的较好比例；书中未分别给出每日克数，但给出ω-3不低于总能量0.5%的口径。
- 饮水量存在直接饮水1200～1500毫升和书中引用指南1500～1700毫升两种口径，来源和语境不同。
- 水果存在200～350克和三种以上、约250克以上等不同表达。
- 豆制品存在单日数量和“不必天天吃”两种表述。
- 部分粮食交换数字没有注明生重或熟重。
- 书中的病例只能说明作者如何分析个案，不能证明同样做法适用于所有人。
- 涉及停药、调整药量、限制蛋白质、钠、钾、磷或液体的内容，必须结合医生意见。
- 书中把部分复杂疾病与营养素建立了较强因果联系，阅读时应区分解释模型、病例经验和经过充分验证的医学结论。
