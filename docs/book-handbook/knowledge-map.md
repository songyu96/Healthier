# 两本书知识地图

[返回手册目录](README.md)

## 总体关系

```text
第一册：健康饮食基础
  身体损伤与修复
    → 七大营养素
      → 食物结构
        → 三餐安排
          → 不同人群调整

第二册：个体化营养管理
  收集健康与饮食信息
    → 识别营养问题
      → 制定可执行方案
        → 监测结果
          → 重新评估
```

第一册主要回答“健康饮食由什么组成、日常应该怎样安排”；第二册主要回答“存在具体健康问题时，怎样形成个体化判断和持续管理闭环”。

## 第一册知识结构

### PART 01：饮食与慢病的基础解释

- 作者用“细胞损伤与修复”解释食物和健康的关系。
- 食物同时提供能量、结构原料和代谢调节物质。
- 能量充足不等于营养完整，现代饮食尤其需要关注营养密度。
- 作者以人类饮食演变说明动物性和植物性食物都不可长期缺位。

### PART 02：七大营养素平衡

- 能量：摄入与消耗相匹配。
- 蛋白质：关注总量、优质蛋白比例和来源轮换。
- 碳水化合物：结合活动量，优先天然复合碳水。
- 脂类：兼顾总量、来源和脂肪酸结构。
- 维生素：区分脂溶性与水溶性，重视食物多样和烹调损失。
- 矿物质：需求虽小但作用广泛，缺乏和过量都要避免。
- 膳食纤维：通过多种植物性食物支持肠道和代谢环境。
- 水：根据环境、运动、食物含水量和身体状态调整。

### PART 03：中国式平衡膳食

- 膳食指南需要结合本国居民的饮食结构理解。
- 日常饮食先保证五大类食物，再关注多样性、轮换和加工程度。
- 早餐、午餐、晚餐承担不同任务；加餐用于弥补缺口。
- 工作、地域、年龄和生理状态会改变实际需要。

### PART 04：具体食物怎样选择

- 分别讨论肉蛋奶鱼、豆类、粮食、食用油、蔬菜和水果。
- 核心判断维度是营养组成、总量、加工、搭配和个人情况。
- 反对因单一风险而把某一整类天然食物永久删除。
- 同时反对把某一种食物包装成能够独立解决健康问题的“神奇食品”。

### PART 05：四类组织解释模型

- 上皮组织：皮肤、黏膜和多种器官表面。
- 结缔组织：骨、软骨、血液和胶原相关结构。
- 肌肉组织：骨骼肌、心肌和平滑肌。
- 神经组织：神经元、髓鞘及支持结构。
- 作者用组织所需原料解释部分症状和疾病；这是理解模型，不是诊断工具。

## 第二册知识结构

### PART 01：营养诊疗流程

- 营养评定。
- 营养诊断。
- 营养干预。
- 营养监测与效果评价。
- 四步构成持续循环，而不是一次性开出固定食谱。

### PART 02～08：疾病专题

- 高血压：盐、能量、蛋白质、脂肪、矿物质、纤维、活动和情绪。
- 血脂异常：区分食物脂肪、体脂和血脂，关注碳水与脂肪酸结构。
- 糖尿病：理解血糖来源、胰岛素、餐后反应和食物组合。
- 慢性肾病：根据分期、营养状态和治疗方式调整蛋白质等目标。
- 痛风：同时考虑尿酸生成、排泄、嘌呤、酒精、糖和进食规律。
- 肿瘤：关注营养不良、治疗耐受、进食障碍和持续监测。
- 心脏疾病：先区分心肌、瓣膜、心衰、动脉和心律问题。

## 从知识到行动的共同路径

```text
判断自己属于健康管理还是疾病管理
  → 估算能量与活动水平
    → 检查七大营养素来源
      → 检查五类食物与三餐结构
        → 找出最重要的1～3个缺口
          → 形成可执行调整
            → 按周记录趋势并重新评估
```

## 四类组织理解框架

### 上皮组织

- 承担屏障、吸收、分泌和保护等功能。
- 作者重点联系蛋白质、脂类、维生素A及其他参与更新的营养素。
- 上皮组织疾病原因复杂，不能简单归因于某一种营养素不足。

### 结缔组织

- 包括骨、软骨、血液以及胶原相关组织。
- 蛋白质提供氨基酸，维生素C参与胶原形成，矿物质参与骨骼等结构。
- 直接吃胶原蛋白不等于胶原会原样到达皮肤或关节。

### 肌肉组织

- 包括骨骼肌、心肌和平滑肌。
- 肌肉维护和收缩需要蛋白质、能量以及多种矿物质参与。
- 便秘、抽筋或心脏症状原因复杂，不能据此自行诊断营养素缺乏。

### 神经组织

- 神经元和髓鞘的结构与蛋白质、脂类及多种微量营养素有关。
- 书中强调磷脂、胆固醇、ω-3脂肪酸、B族维生素、锌和碘等营养素。
- 情绪、认知和神经系统疾病不能归结为单一营养问题。
