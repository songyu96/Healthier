# 营养诊疗流程

[返回手册目录](README.md)

第二册的核心方法不是提供一张通用疾病食谱，而是建立持续循环的营养管理流程。

## 1. 营养评定

- 收集并核实与营养有关的信息。
- 基本资料包括性别、年龄、身高、体重、祖籍、居住地和家庭生活情况。
- 工作资料要具体到实际体力和脑力消耗，不能只看职业名称。
- 医疗资料包括现病史、既往史、家族史、生长发育史、症状和体征。
- 饮食资料包括长期频率、单次摄入量、咀嚼、吞咽和消化能力。
- 生活方式包括运动、家务、睡眠、情绪、吸烟、饮酒和其他习惯。
- 还要了解药物、营养补充剂、化验、影像检查、体检报告和特殊营养需求。
- 经济条件、食物获取、购物做饭能力和家庭支持会影响方案能否执行。

## 2. 营养诊断

- 疾病诊断不等于营养诊断，同一种疾病可以对应不同的营养问题。
- 需要判断总能量是多还是少，三大营养素比例是否合理。
- 需要判断蛋白质、脂肪酸、维生素、矿物质、膳食纤维和水的来源与可能缺口。
- 还要考虑胃肠功能、营养不良、实验室指标、药物与营养相互作用及外界条件限制。
- 诊断应找出当前最重要、最可处理的问题，而不是简单罗列全部异常。

## 3. 营养干预

- 先确定目标，再把问题按重要性排序。
- 一次优先处理少数主要问题，不要求同时改变所有习惯。
- 方案应有依据，并与疾病阶段、用药和其他健康问题协调。
- 计划要接近日常饮食，考虑作息、口味、烹调、经济和食物可获得性。
- 方案必须能够执行；无法落实的复杂食谱没有实际价值。
- 改变可以分阶段进行，并事先说明预期多久能够观察到变化。

## 4. 营养监测与效果评价

- 通过体重、腰围、症状、饮食执行情况、化验和疾病相关指标评价效果。
- 不同指标变化速度不同，复查周期应根据问题确定。
- 达到部分目标后，要根据新的身体和饮食状态重新评估。
- 完整过程是“评定—诊断—干预—监测—再次评定”的闭环。

## 5. 半定量饮食调查

- 重点观察近三个月的习惯，而不是用某一天代表长期饮食。
- 先记录每天频率，再记录每周或每月频率。
- 频率乘以平均单次摄入量，可以换算为近似日均摄入量。
- 频率和单次量都是估算，不应伪装成绝对精确结果。
- 碳水来源要同时计算粮食和水果等食物。
- 优质蛋白质要综合肉、蛋、奶、鱼和内脏等来源。
- 烹调油难以直接计算时，可结合肥肉、内脏、坚果和油炸食品判断，但不能据此生成确定克数。
- 蔬菜和水果调查强调新鲜食物。
