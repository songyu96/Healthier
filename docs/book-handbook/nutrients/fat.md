# 脂类

[返回手册目录](../README.md)

## 主要作用

- 提供能量并形成能量储备。
- 参与构成细胞膜、磷脂和胆固醇等结构。
- 帮助维生素A、D、E、K等脂溶性维生素吸收。
- 为部分器官提供支撑和保护。
- 提供人体不能自行合成的必需脂肪酸。

## 脂肪来源

- 动物性来源包括肉、蛋、奶、鱼和动物内脏等。
- 植物性来源包括烹调油、坚果和种子等。
- 书中建议总脂肪大致一半来自动物性食物，一半来自植物油和坚果。
- 脂肪不是越少越好，应先保证合理总量，再考虑脂肪酸结构。

## 脂肪酸类型

- 饱和脂肪酸常见于动物脂肪、椰子油和棕榈油。
- 单不饱和脂肪酸较多的油包括茶籽油和橄榄油。
- 多不饱和脂肪酸常见于部分植物油、坚果和鱼类。
- 书中提出饱和、单不饱和、多不饱和脂肪酸可参考约`3∶4∶3`。
- 应尽量减少含反式脂肪酸的深加工食品。

## 必需脂肪酸

- ω-6系列的亚油酸和ω-3系列的亚麻酸是书中介绍的两类必需脂肪酸，需要从食物获得。
- 书中认为两类必需脂肪酸合计不应少于总能量的3%。
- 书中给出的较好比例是：`ω-3∶ω-6＝1∶4～6`。
- 书中认为ω-3每日摄入量不应低于总能量的0.5%；这是供能比例，不是固定克数。
- ω-6主要来自日常使用的多种植物油。
- ω-3来源包括深海鱼、贝类、亚麻籽、部分坚果和马齿苋。
- 日常饮食通常更容易获得ω-6，因此书中强调增加ω-3来源。
- 书中没有分别规定ω-3和ω-6每日应摄入多少克，但给出了上述ω-3最低供能比例。

## 总量

- 书中列出的脂肪供能一般范围为总能量的20%～30%，健康模式取30%。
- 书中另有“每日摄入量不能低于总能量30%”的章节表述，两种口径存在张力。
- 脂肪克数可用“每日总能量×脂肪供能比例÷9”估算。
- 书中作者提出膳食胆固醇每日300～500毫克；这是书中口径，尚未按现行指南核验。
- 疾病章节中的脂肪比例是特定方案，不能覆盖健康人的一般口径。
