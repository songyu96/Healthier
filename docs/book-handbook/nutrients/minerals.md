# 矿物质

[返回手册目录](../README.md)

## 总体认识

- 矿物质参与骨骼、体液平衡、神经肌肉活动、氧运输、激素和酶系统。
- 不同矿物质需要量不同，不能因为需要量小就忽略，也不能认为越多越好。
- 书中强调多样化食物和适量摄入，不建议照搬他人的补充方案。
- 居住环境、出汗、疾病、药物和吸收能力都可能改变矿物质状态。

## 钙

- 大部分钙储存在骨骼和牙齿，少量钙参与神经肌肉活动和凝血。
- 奶和奶制品是书中优先推荐的日常来源。
- 豆类、芝麻、部分绿叶蔬菜和海产品也可以提供钙。
- 维生素D、草酸、植酸、消化吸收能力和部分药物会影响钙的利用。
- 血钙正常不能直接证明骨钙充足，抽筋也不能单独证明缺钙。

## 镁

- 参与多种酶反应、能量代谢和神经肌肉活动。
- 来源包括绿叶蔬菜、坚果、全谷物、豆类和部分海产品。
- 大量出汗可能增加电解质损失，但不能仅凭运动量或抽筋判断缺镁。
- 肾功能异常时，大剂量镁制剂可能带来风险。

## 铁

- 参与血红蛋白、肌红蛋白和多种代谢酶的形成。
- 红肉、动物血和肝脏提供较易吸收的血红素铁。
- 豆类、全谷物和绿叶蔬菜提供非血红素铁。
- 维生素C有助于非血红素铁吸收；植酸、草酸和茶等可能影响其吸收。
- 疲劳、头晕和脸色苍白不能区分缺铁、失血或其他原因，贫血类型需要检查确认。

## 锌

- 参与生长发育、组织修复、味觉和免疫等过程。
- 肉类、贝类、蛋奶等动物性食物通常利用率较高。
- 豆类、粮食和坚果也含锌，但植酸等成分可能影响吸收。
- 书中提出每日摄取量不要超过15毫克；补充剂过量同样存在风险。

## 碘

- 是合成甲状腺激素的重要原料。
- 来源包括加碘盐、海带、紫菜和部分海产品。
- 缺乏和过量都可能产生问题。
- 碘容易受储存和烹调方式影响。
- 甲状腺结节或甲状腺疾病不能直接等同于缺碘或碘过量，调整摄入前应结合诊断。
