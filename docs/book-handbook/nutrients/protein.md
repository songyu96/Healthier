# 蛋白质

[返回手册目录](../README.md)

## 主要作用

- 构成细胞、肌肉、酶、抗体和多种功能物质。
- 参与组织生长、更新和损伤修复。
- 能量不足时也可能被用于供能，但这不是书中希望的主要用途。

## 主要来源

- 肉、蛋、奶和鱼是书中强调的优质蛋白质来源。
- 谷物、豆类、坚果等植物性食物也提供蛋白质。
- 动物性蛋白质的氨基酸组成通常更接近人体需要。
- 豆浆与牛奶、豆制品与肉蛋奶鱼的营养组成不同，不能简单视为完全等价替代。

## 平衡方法

- 书中建议动物蛋白质约占总蛋白质的一半，其余由植物性食物提供。
- 健康人的蛋白质供能比例取总能量的10%～15%，书中的健康模式使用15%。
- 书中部分案例还使用每千克标准体重1～1.2克作为参考，两种算法可能产生不同结果。
- 不要求每天精确到1克，可结合一周内肉、蛋、奶、鱼和豆类的摄入情况回顾。
- 儿童、孕产妇、运动员、老年人、营养不良者和患者的需要不同。
- 肾病、肝病等情况下，蛋白质总量和来源必须结合病情判断。

## 食物估算

- 一个中等鸡蛋约含6～7克蛋白质。
- 100毫升牛奶约含3克蛋白质。
- 100克瘦肉或鱼约含17～20克蛋白质。
- 这些数字是书中的近似估算，不代表不同品种和烹调状态完全相同。
