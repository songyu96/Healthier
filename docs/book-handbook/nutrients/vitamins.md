# 维生素

[返回手册目录](../README.md)

## 总体认识

- 维生素本身不是主要能量来源，但参与代谢调节和组织维护。
- 脂溶性维生素包括A、D、E、K，需要膳食脂肪帮助吸收，也更容易在体内储存。
- 水溶性维生素主要包括B族和C，较容易在清洗、浸泡、久煮和高温加工中损失。
- 长期偏食、食物种类少、蔬果不足或动物性食物不足，都可能造成来源单一。
- 不能根据疲劳、口腔溃疡、眼干等非特异症状直接判断缺乏某一种维生素。

## 维生素A

- 与正常视觉以及皮肤、眼睛、呼吸道等上皮组织的维护有关。
- 动物肝脏、蛋和奶制品可直接提供维生素A。
- 胡萝卜、南瓜和深绿色蔬菜等提供类胡萝卜素，可在体内转化。
- 类胡萝卜素属于脂溶性成分，与含适量脂肪的正餐搭配更有利于利用。
- 食物来源和补充剂的风险不同，不能因为营养素重要就长期自行大剂量补充。

## 维生素D

- 与钙磷吸收和骨骼健康密切相关。
- 来源包括部分鱼类、蛋、奶、强化食品以及皮肤在日照条件下的合成。
- 日照效果受季节、纬度、肤色、衣着和生活方式影响。
- 维生素D和钙应结合起来理解，不能只关注钙摄入。
- 是否缺乏以及是否需要补充，应结合检测和个人情况判断。

## B族维生素

- B族不是一种营养素，而是一组参与能量代谢、神经功能和细胞更新的维生素。
- 书中重点介绍B1、B2、B6、B12和叶酸。
- 全谷物、种子外层、瘦肉、蛋奶、豆类、绿叶蔬菜、坚果和动物性食物共同构成主要来源。
- B12主要来自动物性食物，长期严格素食者需要特别注意来源。
- 不能把某一种补充剂配比直接当作所有人的通用方案。

## 维生素C

- 参与胶原形成和抗氧化过程，并有助于植物性非血红素铁的吸收。
- 新鲜蔬菜和水果是主要来源。
- 长时间浸泡、反复清洗和久煮会增加损失。
- 完整水果和蔬菜应共同提供维生素C，果汁饮料不能作为等价来源。
- 植物性铁来源可以与富含维生素C的新鲜蔬果搭配。
