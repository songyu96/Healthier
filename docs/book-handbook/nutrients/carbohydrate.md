# 碳水化合物

[返回手册目录](../README.md)

## 主要作用

- 是身体的重要能量来源。
- 葡萄糖参与大脑、肌肉和其他组织的能量供应。
- 碳水化合物并非越少越好，关键是总量、来源和活动量相匹配。

## 主要来源

- 谷物、薯类、杂豆和水果都可以提供碳水化合物。
- 添加糖、甜饮料、甜点和高度精制主食也提供碳水，但营养密度通常较低。
- 土豆、山药、莲藕、粉条、粉丝和淀粉类小吃应计入主食或碳水来源，不能全部当作普通蔬菜。

## 平衡方法

- 书中给出的碳水供能范围为总能量的55%～65%，健康模式使用55%。
- 体力活动越多，碳水化合物需要通常越高。
- 运动少的脑力劳动者可以降低粮食总量，但书中仍建议保证约150克粮食。
- 来源上应增加全谷物、杂豆和薯类，减少添加糖及过度精制的米面制品。
- 消化能力较差时，可以阶段性选择容易消化的食物，但不能长期只靠白粥等单一食物。

## 食物交换

- 书中使用近似交换：50克白米或白面约相当于200克薯类，或约400克苹果、梨所含的碳水化合物。
- 水果明显增加时，应考虑相应减少其他碳水来源，但水果不能替代整顿饭。
- 书中部分粮食数字没有明确说明生重或熟重，因此不能在状态不明时进行精确换算。
