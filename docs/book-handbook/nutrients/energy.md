# 能量平衡

[返回手册目录](../README.md)

## 1. 能量的来源与去向

- 碳水化合物、脂肪和蛋白质都能提供能量。
- 酒精也能提供能量，但不是人体必需营养素。
- 能量主要用于基础代谢、身体活动、食物消化吸收和维持体温等过程。
- 运动量、脑力活动、熬夜、吸烟、饮酒和疾病状态都会影响身体的营养消耗或修复负担。

## 2. 书中的能量估算方法

- 标准体重按 `身高（厘米）－105` 估算。
- 每日能量按“标准体重×活动系数”估算。
- 书中使用的活动系数为：长期卧床25、轻体力30、中体力35、重体力40千卡/千克。
- 轻体力且偏胖者，书中提出可把活动系数由30调整为25，但没有给出统一的“偏胖”判断标准。
- 年龄增加、长期消耗下降时，应相应调整总能量；活动明显增加时，总能量也要增加。

## 3. 不能只看体重

- 体重正常不等于身体组成合理，还要注意腰围、体脂和肌肉情况。
- 摄入超过消耗，可能增加脂肪储存；摄入不足，则可能造成体重、肌肉或功能下降。
- 调整体重不能只靠减少某一种营养素，应同时保证营养密度和基本结构。
