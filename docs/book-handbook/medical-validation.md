# 医学核验状态

[返回手册目录](README.md)

本文件用于区分“准确复述书中内容”和“已经按现行医学证据核验”。当前手册的首要目标是忠实整理两本书，尚未对全部观点完成独立医学核验。

## 状态定义

| 状态 | 含义 | 可否直接作为健康建议 |
|---|---|---|
| 书中观点 | 已确认书中有此表述 | 只能注明“书中认为” |
| 书中引用旧版指南 | 书中引用2016版或更早资料 | 需核对当前版本 |
| 病例或作者经验 | 来源是病例叙述或临床经验 | 不能外推为普遍疗效 |
| 待现行证据核验 | 尚未对照当前权威资料 | 不能包装成医学共识 |
| 已核验 | 已记录权威来源、版本和日期 | 仍需保留适用范围 |

## 后续核验原则

- 优先使用现行中国居民膳食指南和中国居民膳食营养素参考摄入量。
- 疾病专题优先使用相关国家指南、专业学会指南和系统综述。
- 每次核验必须记录资料名称、发布机构、版本、发布日期和访问日期。
- 与书中一致时记录“一致”；不完全一致时记录差异及适用条件。
- 证据不足时保留“尚不能确认”，不替作者补充结论。
- 医学核验内容与书中原意分栏保存，不直接改写书中知识点。

## AI安全要求

- 未标记“已核验”的内容，不得称为当前医学共识。
- 不得根据症状自动推断缺少某种营养素。
- 不得根据病例生成停药、改变药量或替代治疗的建议。
- 不得把患者的蛋白质、脂肪、钠、钾、磷或液体目标套给健康人。
