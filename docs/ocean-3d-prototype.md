# 海洋 3D 视觉原型

## 范围

- `/game` 展示一个持续自由泳的角色、波动海面、远处海岛、棕榈与浮标。
- 角色沿半径 100 米的环形航线实际位移，镜头跟随位置和朝向；浮标固定在航线旁，提供经过与前进的参照。动画距离不写入游戏计分，重新进入场景会从起点开始。
- 海面使用五组不同方向、波长和速度的涌浪，GPU 波面与角色浮动共用参数；逐像素法线、分层流动细波、视角反射与局部尾流替代重复铺设的水纹贴图，远处细节会逐渐减弱以减少闪烁。
- 拖动环绕、滚轮/双指缩放；提供跟随、俯瞰、看海三个预设镜头。
- 支持暂停、均衡/省电画质及轻量 SVG 场景；离屏或后台停止持续绘制，减少动态效果偏好默认暂停。
- WebGL2 不可用、模型加载异常或上下文丢失时回退轻量场景；失败后“重新加载 3D”刷新页面重试，清除失败的模块/模型缓存。正常切换轻量场景无需刷新。
- 沿用已有男女角色选择及 `gamePresentation` 的节奏和比例参数。身高体重仅影响有限的视觉比例，不推断游泳能力；已有安全受限规则保持不变。
- 不新增游戏计分、历史、备份字段或情绪评价。

## 资产与加载

角色来自 MakeHuman 的 CC0 数据，来源、许可、版本及源文件哈希见 `src/ocean/assets/README.md`。`scripts/build-swimmer.mjs` 可从固定源数据重新生成 GLB，不是日常构建步骤。

Three.js、React Three Fiber 和场景代码按需加载；模型从本站读取，不依赖外部 CDN。3D JS 与 GLB 不在首次 PWA 预缓存中。已有 Service Worker 控制页面时，访问 3D 会写入独立运行时缓存（最多 8 个资源、30 天）；未缓存时离线访问会回退轻量场景。

## 真实感与后续边界

这是验证视觉方向、骨骼动画、交互与移动端布局的原型。男女选项共用一个基础人体网格，以泳帽、泳衣色彩和有限比例区分；还没有两个独立制作的角色。自由泳为程序驱动，不是动作捕捉。海岛为程序地形，未使用扫描地形或照片材质。

3D 暂未制作已解锁伙伴和进阶泳姿；解锁记录与界面列表保持原有功能，轻量场景保留原有展示。下阶段应先评审画面，再制作独立角色、专业游泳动作、海岸 PBR 材质及伙伴互动。

## 验证

- 自动测试：镜头复位、暂停、画质、失败重试、减少动态效果偏好、划水循环、WebGL 能力检查，以及位移速度、暂停/恢复、航线闭合与岛屿间距、镜头跟随时保持观察角度和缩放。
- 浏览器：桌面与窄屏布局、角色选择、镜头/画质切换、主动丢失 WebGL 上下文后回退及恢复。
- PWA：生产预览的运行时缓存包含 3D JS 和 GLB，受 Service Worker 控制的页面断网刷新后仍可加载 3D。
- 工程检查：`npm run typecheck`、`npm test`、`npm run lint`、`npm run build`、`npm run verify:pwa`。
- 窄屏浏览器检查不代表真实低端手机性能测量；尚未在 iOS/Android 真机完成帧率与耗电验收。

现有 ESLint 开发依赖链中的 `js-yaml@4.3.1` 有 npm audit 告警，基线锁文件也包含该版本。本次不调整无关依赖；新增 3D 依赖未出现在此次审计告警中。
