# 书中规则计算样例与验收基线

版本：0.1  
用途：后续实现自动测试时的权威预期值。

## 1. 数值比较约定

- 内部计算保留完整精度。
- 界面能量显示到整数 kcal，营养素显示到0.1克。
- 测试浮点误差容许值为 `±0.01`。
- 书中已四舍五入的数字同时保存“精确推导值”和“书中显示值”。

## 2. 案例 F-E-001：175厘米轻体力男性

### 来源

- 第一册“能量平衡的方法因人而异”：`index_split_024.html`
- 第一册“早餐一定要吃够100分”：`index_split_076.html`

### 输入

```text
性别：男
年龄：54
身高：175cm
当前体重：72kg
活动：轻体力
额外运动：无
超重调整：关闭
```

### 预期

```text
标准体重 = 175 - 105 = 70kg
活动系数 = 30
每日能量 = 70 × 30 = 2100kcal

碳水 = 2100 × 0.55 ÷ 4 = 288.75g
蛋白质 = 2100 × 0.15 ÷ 4 = 78.75g
脂肪 = 2100 × 0.30 ÷ 9 = 70g

动物蛋白 = 39.375g
植物蛋白 = 39.375g
植物脂肪参考 = 35g
动物来源脂肪参考 = 35g

蛋白质交叉校验 = 70～84g
早餐能量范围 = 700～1050kcal
早餐动物蛋白三等分参考 = 13.125g
```

说明：早餐章节为了讲解取总蛋白80克、动物蛋白40克，因此写出约13.3克和晚餐无动物食物时20克。PWA 保留公式精确值，并在案例说明中展示书中近似值。

### 书中食物落地示例

```text
鸡蛋1枚 + 牛奶300ml + 肉或鱼约150g
```

这是动物蛋白的近似组合，不代表一整天完整食谱。

## 3. 案例 F-E-002：178厘米电脑工作者

### 来源

第一册“蛋白质的平衡”：`index_split_029.html`。

### 输入

```text
性别：男
年龄：30多岁
身高：178cm
当前体重：78kg
工作：每天电脑工作
运动：每周篮球1次
活动：轻体力
```

### 预期

```text
标准体重 = 178 - 105 = 73kg
每日能量 = 73 × 30 = 2190kcal
蛋白质 = 2190 × 0.15 ÷ 4 = 82.125g
书中显示值 ≈ 82g
动物蛋白 = 41.0625g
书中显示值 ≈ 41g
```

按同一健康比例推导、但书中该案例未逐项展示：

```text
碳水 = 301.125g
脂肪 = 73g
```

### 书中食物落地示例

```text
瘦肉约150g + 鸡蛋1枚 + 牛奶200ml
```

一周范围允许鱼、畜禽、蛋奶互换和补足。

## 4. 案例 F-E-003：185厘米轻体力程序员

### 来源

第一册“脂类平衡的方法”：`index_split_039.html`。

### 输入

```text
身高：185cm
工作与生活：约75%坐、25%站
活动：轻体力
```

### 预期

```text
标准体重 = 185 - 105 = 80kg
每日能量 = 80 × 30 = 2400kcal
脂肪供能 = 2400 × 0.30 = 720kcal
脂肪 = 720 ÷ 9 = 80g
动物来源脂肪参考 = 40g
植物来源脂肪参考 = 40g
```

书中粗略食物示例为约30毫升炒菜油加20克坚果。此示例不能反推为所有油和坚果的统一换算系数。

## 5. 案例 F-B-001：早餐能量和结构满分

### 输入

```text
每日目标：2100kcal
早餐摄入：700kcal
早餐包含：粮食、动物性食物、蔬菜、水果、油脂
```

### 预期

```text
能量得分 = 50
结构得分 = 5 × 10 = 50
总分 = 100
评价 = 完美
```

### 边界测试

```text
早餐350kcal且五类齐全：能量25分 + 结构50分 = 75分
早餐700kcal且只有粮食、动物性食物：50 + 20 = 70分
```

后两项的线性能量折算是产品操作化规则，不是书中直接给出的分段算法。

## 6. 案例 F-L-001：午餐三足结构

### 输入

```text
午餐包含：蔬菜、蛋白质食物、粮食
近似熟重比例：50%、25%、25%
```

### 预期

```text
类别完整性：通过
熟重近似比例：接近书中餐盘结构
精确餐盘结论：不可得
```

若运动量大，只给“可增加粮食比例”的提示，不自动变成新的固定比例。

## 7. 案例 F-X-001：碳水食物交换

### 来源

第一册 `index_split_034.html` 和 `index_split_121.html`。

### 书中近似关系

```text
50g白米/白面 ≈ 200g薯类 ≈ 400g苹果或梨
25g米面中的碳水 ≈ 200g苹果中的碳水
```

### 验收要求

- 必须同时保存食物状态；状态未知时不执行自动精确替换。
- 水果替换部分主食后，仍需保留蛋白质、脂肪和其他食物组，不能生成水果代餐建议。

## 8. 案例 F-W-001：饮水区间

### 输入

```text
普通天气、无大量出汗、无额外运动
```

### 预期

```text
直接饮水参考 = 1200～1500ml/日
```

天热、出汗和运动只触发“需要增加”的提示；没有书内量化系数，不计算虚构的精确增量。

## 9. 不进入测试基线的案例

### 高活动蛋白案例

第一册 `index_split_027.html` 某案例文字描述与所用活动系数存在不一致，暂不作为权威测试。

### 疾病案例

第二册糖尿病、肾病、肿瘤、高血压等章节中的能量和营养素比例是特定个案或疾病方案，不进入普通健康模式测试。

### 35%动物/65%植物

由于缺少计量口径，仅测试规则能否展示出处和“不可计算”状态，不测试克数比例。

## 10. 最低自动测试清单

后续代码至少应覆盖：

1. 三个身高与活动案例的标准体重、能量和宏量营养素。
2. 超重调整必须由用户主动开启。
3. 蛋白质主公式和每千克交叉校验并存。
4. 早餐能量与五类结构评分。
5. 果汁不计入新鲜水果目标。
6. 未知油脂不会被填成确定克数。
7. 熟重和生重不会被直接混算。
8. 周食物种类正确去重。
9. 疾病安全门阻止普通健康方案被描述为治疗方案。
10. 每条结果可追溯到 `ruleId`、版本和书内出处。
