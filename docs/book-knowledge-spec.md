# 书本章节知识规格

## 1. 目标

应用在饮食记录、计算器、日评价和周总结之外，提供两本书的章节知识入口。内容用于解释规则来源和日常行动，不替代原书，也不提供疾病治疗建议。

## 2. 引用定位

仓库内两本 EPUB 均为流式排版：

- 《你是你吃出来的》目录包含 141 个目录项。
- 《你是你吃出来的2：慢病康复的饮食密码》目录包含 226 个多层目录项。
- 两本 EPUB 都没有 page-list 或 page-map；第一册 NCX 还明确记录 totalPageCount=0、maxPageNumber=0。

因此应用统一展示书名、PART、章节标题、EPUB目录第 X/Y 项、约全书 Z% 位置和 EPUB 内部文件，并明确注明“纸书页码：该 EPUB 未提供”。

不得根据手机屏幕、字号或 HTML 文件编号伪造纸书页码。如果以后获得与当前版本对应的纸书 ISBN 和可靠页码表，可以新增独立的印刷版定位字段。

## 3. 每章内容

每个知识条目至少包含：

- 一段自行转述的章节摘要；
- 2～5条重点知识；
- 1～3条日常可执行行动；
- 关联规则编号；
- 书名、PART、章节名和 EPUB 内部定位；
- 健康模式、知识参考或安全流程的适用标记；
- 必要的适用边界。

公开仓库只保存概括性转述，不复制大段原文。

## 4. 与规则引擎的边界

章节知识是静态说明数据，不参与目标或营养计算。章节知识通过规则编号关联书本规则，计算与评价仍以 domain/rules 为唯一执行入口。

修改摘要不得改变历史目标；修改规则时必须单独升级规则版本并更新测试。

## 5. 覆盖计划

第一阶段收录当前规则规格已经引用的 24 个核心章节，其中第一册 23 个、第二册 1 个。后续按 EPUB 原始目录顺序扩展：

1. 第一册其余健康饮食与基础营养章节。
2. 第一册人群与疾病相关章节，仅作知识或安全提示。
3. 第二册各疾病章节，仅作内容摘要和专业就医边界，不接入健康模式自动建议。

每批扩展都应校验编号唯一、目录位置有效、规则关联存在和疾病内容未进入健康模式。
