# Swimmer asset

## Current anime Coral C assets

`swimmer-male.glb` and `swimmer-female.glb` are separate rigged models generated by `node scripts/build-anime-swimmers.mjs`. They reuse the CC0 body topology and skeleton in the legacy `swimmer.glb` below, with independent body shaping. The generator authors new stylized heads, eyes, hair, cap/goggle geometry and separate skinned garments with cut edges. No third-party character mesh or texture is included.

The selected design is column C of `docs/assets/swimmer-anime-outfits-v2.png`. Preview hair and swim equipment are both exported and selected by per-instance visibility. GLB materials retain base colors; the app applies toon shading. Keep the legacy GLB as a deterministic build input; it is no longer the game's loaded character.
